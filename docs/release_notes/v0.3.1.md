# Logic-Loom v0.3.1

> A rebuild of v0.3.0 whose Linux packages run on current long-term-support
> distributions. The app itself is unchanged.

## Linux packages run on Ubuntu 22.04 and later

The v0.3.0 Linux packages were built on the newest GitHub runner, so they were
linked against glibc 2.43 and refused to start on anything older, including
Ubuntu 24.04 (glibc 2.39) and Debian 13 (glibc 2.41). The Linux build now runs
on Ubuntu 22.04, and the release fails if anything it ships needs a glibc newer
than 2.35. The packages run on Ubuntu 22.04 or later, Debian 12 or later, and
distributions of the same age.

The build also checks that the AppImage carries its own WebKitGTK, so it runs
where the distribution's WebKitGTK is missing or cannot be installed. The
`.deb` still uses the distribution's `libwebkit2gtk-4.1-0`.

macOS and Windows packages are rebuilt from the same source with no changes.
