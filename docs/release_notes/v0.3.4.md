# Logic-Loom v0.3.4

> Fixes from the v0.3.3 retest: tighter checks on the local API, Ctrl-K on Home,
> a quieter backdrop logo, and release checksums that verify. No settings change
> is needed to update, unless you set a custom editor or zsum command from the
> Settings page (see below).

## Security and API

- `GET /api/app/path-exists` only answers for paths inside the folders you
  configured (vault, node folders, workspaces, cache and config folders) and for
  `.yaml` / `.yml` files under your home folder. Anything else, including a path
  with a NUL byte, is a `422`.
- The **editor** setting (`nodes_editor`) can only be set from the app to a known
  editor, such as `code`, `cursor`, `zed`, `subl`, `gedit`, `kate` or `open`,
  with plain flags like `--wait`. Flags that make an editor run commands
  (`vim -c`, `emacs --eval`, ...) are refused.
- The **zsum command** (`zsum_python_cmd`) can only be set from the app to a
  Python, `uv` or `zsum` command, without `-c`.
- Any other program can still be set by editing `config.toml` yourself.
- Saving an API key no longer sends the key back in the response; it comes back
  masked, as on `GET /api/app/config`.
- Saving a prompt variant checks its filename the same way **Validate** does.
- Hidden vault files and folders (`.github`, `.obsidian`, dot-files) can't be
  read or listed by typing their path either: they return `404`.

## Fixes

- **Ctrl-K / ⌘K** opens search on Home too, not only inside a mode.
- Home has a card for every mode. MechDSL, Failure Memory and Records are tagged
  "optional", since they need an extra install or a config entry.
- The backdrop logo is a small mark in the bottom-right corner by default, and
  Home no longer shows a second, overlapping banner. The **Logo** switch still
  offers the full logo.
- zsum ▸ Collections explains how to build a library (Skeleton or Full Run) and
  which cache folder it reads, instead of reporting a missing `index.json`.
- When OpenAlex or Semantic Scholar rate-limits a request (`429`), Discover and
  related-paper walks wait and retry with growing, randomized delays (up to 3
  times, honouring `Retry-After`) instead of a single retry after one second.
- First-run setup reports a vault set through `AKMS_GLOBAL_VAULT`.

## Releases

- `SHA256SUMS.txt` no longer lists itself, so `sha256sum -c SHA256SUMS.txt`
  passes. Releases v0.3.0 to v0.3.3 still have the self-listing line; see
  [Known issues](../known-issues.md).

## For developers

- `POST /api/graph/issues/scan` takes an optional `{"ignore": [paths]}` body;
  unknown fields are a `422`.
- `scripts/release.sh` tags `origin/main` by default and no longer mentions a
  source-repository token.
- CI and release workflows use the Node 24 versions of their GitHub Actions.
