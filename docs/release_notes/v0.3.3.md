# Logic-Loom v0.3.3

> The rest of the v0.3.1 QA pass: screens that left you stuck, features that ran
> but showed the wrong thing, API fixes and a round of polish. No settings change
> is needed to update.

## No more dead ends

- When a mode is not set up (AKMS, MechDSL, Failure Memory, Records), its setup
  message now appears inside the app, with the mode switcher and side menu still
  on screen. Before, the message replaced the whole window and the only way out
  was restarting the app.
- The Failure Memory and Records setup messages have a **Copy snippet** button and
  show which `config.toml` to paste it into.
- "Find related papers" on the Assistant overview opens a batch's **Related** tab
  instead of an empty page.
- A batch's **Runs** tab lists the workflow runs made from it.
- AKMS ▸ Nodes only offers **View in Graph** for nodes that are in the graph.
- zsum ▸ Collections explains what to do when there is nothing to show yet.
- Learn history is kept when you reload the window.

## Features that now show the right thing

- **The Picker lists every batch.** Batches created in the app, including the
  starter batch, were missing from AKMS ▸ Picker. They are all listed now, and
  new or changed batches appear without restarting.
- The vault preview renders LaTeX math and shows nested frontmatter as readable
  text instead of `[object Object]`.
- A graph rebuild that stops for review names the files involved and how to fix,
  ignore or skip them.
- zsum ▸ Settings can create a starter `zsum.config.yaml` when none exists.
- The vault tree hides hidden files and folders (`.github`, `.gitignore`, ...).
- First-run setup accepts a vault path set in `LOGIC_LOOM_VAULT_PATH`.
- Prompt **Preview** shows the resolved prompts. It always came back empty
  before. **Validate** also works on the built-in prompts.

## Clearer messages

- Discover shows a note when OpenAlex or Semantic Scholar is rate-limiting or
  not answering, instead of quietly returning fewer results. A rate-limited
  request is retried once.
- Testing a provider in Assistant ▸ Settings explains a failure (for example a
  Semantic Scholar rate limit) and what to do about it.
- "bbt-path-unset" now reads "Zotero is not connected", with the setting to fix.
- **Open in Editor** says which program it used, or why nothing could open.
- An empty prompt preview in the Run dialog says why no variants were chosen.
- MechDSL ▸ Overview labels each backend as Ready or Not installed.
- Buttons that need input first say so when you hover over them.

## Look and feel

- The window title and icon are Logic-Loom's own, and the Linux packages carry a
  description.
- A **Logo** switch in the top bar dims, hides or restores the backdrop logo. It
  is dimmed by default.
- Dark mode has more contrast for secondary text and borders.
- The Discover search box wraps long queries.
- **Ctrl-K / ⌘K** opens search reliably, also with Caps Lock on, and a cleared
  or changed query no longer shows old results.
- The old `/picker` link opens the Picker again.

## For developers

- `POST /api/assistant/discover/search` validates its body and returns
  `provider_errors`.
- The picker sub-app's routes are listed in `/openapi.json` (tag `akms-picker`)
  and use the standard error envelope.
- `/api/graph/refresh/stream` is a `POST` (it was a `GET`, so a plain link could
  start a rebuild). `/api/graph/status` timestamps are UTC.
- `/api/zsum/test` returns a `502 zsum_test_failed` error when the test fails.
- The unimplemented `POST /api/learn/export` stub is removed.
- The "picker mount skipped" warning at startup is now an info message; it is
  only a warning if the picker still can't mount after the workspace exists.
