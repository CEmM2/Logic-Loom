# Logic-Loom v0.3.0

> The first release whose source is public. The app now runs on AKMS 0.4,
> installs every Python subsystem from PyPI, and adds a Records mode. It also
> carries everything prepared as v0.2.1, which was never tagged.

## Runs on AKMS 0.4, with nothing vendored

Logic-Loom used to carry source snapshots of AKMS, MechDSL and
zotero-summarizer and build from them. All three are now ordinary dependencies
installed from PyPI at the versions the lockfile records:

- `akms`, `akms-learn`, `akms-nodes-gen`, `akms-failure-memory`, `akms-records`
  and `compmech-reference-pack` at 0.4.0,
- `mechdsl-core` and `algo2code` at 0.2.1,
- `zotero-summarizer` at 1.0.0.

The packaged app bundles all of them. Earlier binaries left Failure Memory out
of the frozen sidecar and shipped agent assets from an older AKMS; this one
reads the bundled skills, agents, commands and hooks from the installed AKMS
package, so the assets always match the AKMS version in the binary.

## No AKMS or zotero-summarizer checkout needed

The Picker, Nodes, Batches and Graph tabs no longer need an AKMS source
checkout, and the zsum pipeline no longer needs a zotero-summarizer one. The
`akms_repo`, `zsum_repo` and `logic_loom_root` settings are optional overrides
for development and default to unset. First-run setup and Settings treat them
as optional.

## New: Records mode

A sixth mode, **Records**, browses akms-records stores: an overview, a record
browser, the schemas in use, and a graph of how records relate. It is read-only
and opens only the stores you list under `[[records_stores]]` in the
configuration. akms-records is experimental upstream.

## Failure Memory

The Failure Memory workspace follows AKMS 0.4: the mirror exporter that used to
be a separate tool is built in, so `refresh` in operator mode needs nothing
extra installed.

## Fixes

- `LOGIC_LOOM_*` environment variables now override `config.toml`, as
  documented.
- The graph cache is keyed correctly when no AKMS checkout is configured.
- The batch picker mounts without an AKMS source checkout.

## Security and repository hygiene

- Dependency upgrades clear 30 known advisories in transitive packages
  (anyio, cryptography, filelock, fsspec, multidict, pydantic-settings, pypdf,
  starlette, urllib3).
- The repository now has a license file (MIT), a security policy, contributor
  documentation, dependency and code scanning, and Dependabot.
- `THIRD_PARTY_NOTICES.md` lists every Python, JavaScript and Rust package the
  app ships, with its license and the license texts those packages include. The
  installers carry it next to `LICENSE`.

## Known limitations

- The binaries are not notarized (macOS) or code-signed (Windows). Verify a
  download against the published `SHA256SUMS.txt`.
- MechDSL `verify` needs taichi, which is not bundled; install it from the
  MechDSL overview page in the app.
