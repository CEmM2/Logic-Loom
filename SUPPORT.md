# Support

Logic-Loom is research software maintained on a best-effort basis.

- **Bug reports and feature requests**: GitHub issues.
- **Questions**: GitHub discussions if enabled, otherwise an issue.
- **Security reports**: see `SECURITY.md`; never a public issue.
- **Installers**: prebuilt desktop bundles and their checksums are published at
  [CEmM2/Logic-Loom-releases](https://github.com/CEmM2/Logic-Loom-releases).

There is no commercial support and no guaranteed response time. Clear,
reproducible reports (app version, operating system, the steps, expected vs.
actual behaviour) get answered first.
